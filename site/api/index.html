    API Web de Pokémon Showdown

    La mayoría de los APIs de Pokémon Showdown (PS) a los que querrías acceder programáticamente están disponibles añadiendo .json a la URL original.

    Todos cuentan con la cabecera Access-Control-Allow-Origin: *, por lo que puedes acceder a ellos directamente usando AJAX, fetch, o librerías HTTP como requests en Python.

    Cómo empezar (Python)

    Si eres un desarrollador junior o intermedio, interactuar con el API de Showdown es bastante sencillo. Todas las respuestas están en formato JSON (JavaScript Object Notation), que es un estándar común estructurado en forma de diccionarios y listas que facilita la lectura y manipulación de datos.

    En Python, la forma más fácil de conectarse es utilizando la librería requests.

    Instalación de dependencias

    Primero, asegúrate de tener instalada la librería en tu entorno, recomendamos usar uv para un manejo más rápido de dependencias:

    uv pip install requests

    Ejemplo: Obtener datos de la Pokédex

    A continuación, un ejemplo básico de cómo realizar una petición GET, leer la estructura JSON e imprimir la información.

    import requests

# URL del recurso (Añadimos .json al final o usamos las rutas directas de datos)
url = "https://play.pokemonshowdown.com/data/pokedex.json"

# Realizar la petición GET
response = requests.get(url)

# Comprobar que la petición fue exitosa (Código HTTP 200 significa OK)
if response.status_code == 200:
    # Decodificar y convertir la respuesta JSON a un diccionario de Python
    pokedex_data = response.json()

    # pokedex_data ahora contiene toda la información de los Pokémon.
    # Vamos a buscar la información de Pikachu (la clave suele estar en minúsculas y sin espacios)
    pikachu_info = pokedex_data.get('pikachu')

    if pikachu_info:
        print(f"Nombre: {pikachu_info['name']}")
        print(f"Tipos: {', '.join(pikachu_info['types'])}")
        print(f"Estadísticas Base: {pikachu_info['baseStats']}")
else:
    print(f"Error al conectar con el API: Código de estado {response.status_code}")

    Endpoints Disponibles

    A continuación se listan los principales recursos que puedes consultar.

    Repeticiones (Replays)

    Obtener una repetición específica:

    Puedes obtener los datos de una repetición añadiendo .json al final del enlace de la repetición. El archivo contendrá información detallada como los equipos y el registro de la batalla.

    • JSON: https://replay.pokemonshowdown.com/gen8doublesubers-1097585496.json
    • Registro (Log): https://replay.pokemonshowdown.com/gen8doublesubers-1097585496.log

    Obtener el registro de entrada de una repetición directamente:

    (Solo para formatos donde el equipo se genera automáticamente)

    • Input Log: https://replay.pokemonshowdown.com/gen8randombattle-2005209836.inputlog

    Nota: Los logs e inputlogs también están disponibles dentro de la respuesta JSON principal, por lo que las formas .log y .inputlog se proveen solo por conveniencia.

    Búsqueda de Repeticiones (Replay search)

    Puedes buscar repeticiones usando parámetros en la URL.

    • Listar repeticiones recientes: https://replay.pokemonshowdown.com/search.json
    • Buscar por usuario: https://replay.pokemonshowdown.com/search.json?user=zarel
    • Buscar por múltiples usuarios: https://replay.pokemonshowdown.com/search.json?user=zarel&user2=yuyuko
    • Buscar por formato (tier): https://replay.pokemonshowdown.com/search.json?format=gen8ou
    • Búsqueda combinada: https://replay.pokemonshowdown.com/search.json?user=zarel&user2=yuyuko&format=gen7randombattle
    • Paginación de búsquedas: https://replay.pokemonshowdown.com/search.json?user=zarel&before=1372221987

    Paginación: Las búsquedas están limitadas a 51 resultados, y las páginas se desplazan de a 50 cada vez. Si existe un resultado 51 dentro de la estructura de respuesta, significa que hay al menos una página más disponible. Para el parámetro de tiempo (before), utiliza el uploadtime (tiempo de subida) de la última repetición en la lista.

    Tampoco recomendamos usar el parámetro opcional page=[number], ya que es un API antiguo con poco soporte y no deberías depender de este.

    Usuarios (incluyendo información de la clasificación/ladder)

    Puedes obtener la información del perfil público de un usuario y su posición (Elo) en las distintas categorías de clasificación (ladder).

    • https://pokemonshowdown.com/users/zarel.json

    Clasificaciones (Ladders)

    Obtén los top jugadores y su Elo respectivo de un formato en específico.

    • https://pokemonshowdown.com/ladder/gen8ou.json

    Noticias (News)

    Puedes consultar en formato JSON las noticias recientes y anuncios importantes mostrados en la página principal.

    • Todas las noticias recientes: https://pokemonshowdown.com/news.json
    • Una noticia específica (por ID de noticia): https://pokemonshowdown.com/news/270.json

    Recursos de la Pokédex (Dex resources)

    Directamente desde los repositorios de datos del simulador, estos endpoints son sumamente útiles para construir bots de Discord, herramientas de análisis u otras aplicaciones que requieran información estadística del juego.

    • Dicionario completo de la Pokédex: https://play.pokemonshowdown.com/data/pokedex.json
    • Dicionario completo de Movimientos (Moves): https://play.pokemonshowdown.com/data/moves.json
