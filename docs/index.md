# Introducción a Pokémon Showdown

Pokémon Showdown es muchas cosas:

- Un **sitio web** que puedes usar para combatir en Pokémon
  - [pokemonshowdown.com](http://pokemonshowdown.com/)
- Una **librería de JavaScript** para simular combates Pokémon y obtener datos de la Pokédex
  - [Simulador y Librería JS](js-library.md)
- Algunas **herramientas de línea de comandos (CLI)** para simular combates (que pueden ser usadas en programas que no son de JavaScript)
  - [Herramientas CLI](cli.md)
- Un **API web** para el sitio web de combates Pokémon
  - [Documentación del API](api.md)
- Un **servidor de juego** para alojar tu propia comunidad de Pokémon Showdown y modos de juego

Pokémon Showdown simula combates individuales, dobles y triples en todos los juegos lanzados hasta ahora (Generaciones 1 a 9).
